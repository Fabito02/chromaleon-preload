## Notes:
> [!WARNING]
> This is an additional feature for the [ChromaLeon GNOME Shell extension](https://github.com/Fabito02/ChromaLeon). It is in an early stage and may cause bugs.

## Installation

```bash
# Clone the repository
git clone https://github.com/Fabito02/chromaleon-preload

# Enter the directory
cd chromaleon-preload

# Run the installation
./manage.sh -i
```

> **Note:** After installation, it is necessary to restart the session.

## Uninstallation

```bash
./manage.sh -u
```
